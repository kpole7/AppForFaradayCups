# AppForFaradayCups
The goal of the project is to create an application that acts as a graphical user interface for a specialized external device. The device controls up to three Faraday cups for measuring ion beams. The application connects to the external device via the Modbus protocol (the application is the master).

The application is written in C++ based on the FLTK library and only works on Linux Mint (it is not portable).
